# Excel Data Cleaning & Analysis Tool

## 📌 Description
A Python CLI tool to clean, analyze, and process Excel data using Pandas.

## 🚀 Features
- Load Excel files
- Remove duplicates
- Handle missing values
- Standardize column names
- Data analysis (mean, median, summary)
- Filtering & searching (case-insensitive)
- Save cleaned data to Excel/CSV

## 🛠 Technologies
- Python
- Pandas

## ▶️ How to Run
1. Install dependencies:
   pip install pandas openpyxl

2. Run program:
   python main.py

## 📂 Project Structure
- main.py → Menu system
- cleaner.py → Data cleaning
- analyzer.py → Data analysis
- utils.py → Filtering & saving

## 📊 Output
- Cleaned Excel file
- CSV file
- Analysis in terminal
